# TetraCrest Backend

This backend package provides the initial enterprise skeleton for the TetraCrest Enterprise Operating System.

## Getting started

1. Create and activate a virtual environment.
2. Install dependencies with `pip install -r requirements.txt`.
3. Start the API with `uvicorn main:app --reload`.

## Included capabilities

- FastAPI application scaffold
- Health endpoint
- Authentication scaffold with JWT-based login and refresh tokens
- RBAC and permission scaffolding
- Structured logging
- Configuration management
- Exception handling
- Docker support
- Testing scaffold
